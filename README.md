# 🛵 Rapido Bike Taxi Performance & Analytics Dashboard

Hey there! 👋 Welcome to my Rapido Bike Taxi Data Analytics project. 

In this multi-page project, I dove deep into ride-hailing data to understand operational efficiency, customer behavior, and revenue trends. I managed the complete end-to-end data workflow—starting with raw data cleaning in **Excel**, writing queries and managing data in **MySQL Workbench**, and finally designing a comprehensive, brand-themed interactive dashboard in **Power BI**.

---

## 🛠️ Tools & Tech Stack
* **Microsoft Excel:** Data preprocessing, handling missing values, and cleaning raw dataset rows.
* **MySQL Workbench:** Writing and executing SQL scripts for data extraction, manipulation, and aggregating key ride metrics.
* **Power BI:** Building multi-page interactive dashboards, writing DAX measures, and applying custom UI/UX styling.

---

## 📑 Multi-Page Dashboard Structure
To provide a clean and deep-dive experience, I structured this report into 5 dedicated analytical pages:
1. **Overall Page:** Executive summary tracking total bookings, total booking values, ride volume trends, and overall booking status distribution.
2. **Vehicle Type Page:** Granular performance breakdown across various vehicle categories (Prime Sedan, Prime SUV, Prime Plus, Mini, Auto, Bike, and E-Bike) comparing booking values and travel distances.
3. **Revenue Page:** Financial analysis highlighting revenue generation across payment methods (Cash, UPI, Credit/Debit cards), top customers, and daily travel trends.
4. **Cancellation Page:** Detailed analysis tracking cancellation volumes, rates, and specific root causes for both customer-side and driver-side cancellations.
5. **Ratings Page:** Service quality monitoring comparing driver and customer ratings across all vehicle types.

---

## 🎨 Dashboard Design & Aesthetics
I styled this dashboard using Rapido’s signature **yellow and dark brand identity**. By combining custom page navigation, clean KPI cards, and consistent color palettes, the dashboard delivers a smooth and professional user experience.
